<p>The 0.1.0 preview is the first Docspress-owned source tree. It carries forward the reference design's strongest idea: ordinary WordPress Page hierarchy can become a calm documentation site without a custom post type.</p>

<p>The preview includes the branded theme source, a 1200×900 screenshot, helper tests for tree and heading behavior, and a package script that produces a clean one-folder ZIP. It is intentionally not a public release yet.</p>

<p>The next gate is the real WordPress site: activate the exact ZIP on the isolated `docspress` subsite, enter this content, and verify the desktop and mobile reading paths.</p>
