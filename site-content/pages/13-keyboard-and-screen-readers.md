<h2>Every region has a route</h2>
<p>The header, documentation navigation, page TOC, main content, and footer expose names that help assistive technology describe the page. The skip link moves directly to the primary content.</p>

<h2>Toggle and link are different actions</h2>
<p>In the Docs Tree, the arrow button expands a branch and the adjacent title opens the Page. This avoids making a reader choose between navigation and disclosure with one ambiguous control.</p>

<h2>Drawers return focus</h2>
<p>Mobile drawers expose a close control, respond to Escape, make inactive panels inert, and return focus to the opener when closed. These behaviors still need real-browser verification at each release.</p>
