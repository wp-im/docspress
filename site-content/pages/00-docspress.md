<p>Docspress is a WordPress Classic Theme for sites where the document matters more than the dashboard around it.</p>

<p>It keeps the source of truth familiar: Pages, parent relationships, menu order, excerpts, headings, media, and ordinary Posts. The theme turns those existing editorial decisions into a calm documentation surface.</p>

<p>Start with the sections below, or read the short <a href="/docspress/start-here/">Start here</a> guide if this is a fresh installation.</p>

<hr class="home-intro-rule" />

<div class="home-columns">
	<div class="home-note"><h3>Native content</h3><p>No custom post type is required for the core Docs Tree. Your Pages remain useful if the theme changes.</p></div>
	<div class="home-note"><h3>Editorial rhythm</h3><p>A wide reading rail, restrained accent, and responsive navigation give long text room to breathe.</p></div>
</div>
