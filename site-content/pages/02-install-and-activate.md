<h2>Install the preview</h2>
<ol class="docspress-steps">
	<li>Upload the Docspress ZIP from Appearance → Themes → Add New → Upload Theme.</li>
	<li>Activate Docspress on the demo site only. Keep the main network site unchanged.</li>
	<li>Create the root Page and the section Pages before configuring the theme.</li>
	<li>Set the root Page as the static front page, then choose the same Page as Docs Root in the Customizer.</li>
</ol>

<h2>Finish the surface</h2>
<p>Create a primary menu for the short global links, optionally create a footer menu, and add a site logo only if the site has one that remains legible at a small size.</p>

<div class="docspress-definition"><b>Important</b><p>The theme ZIP does not contain demo content. This site-content folder is the reviewed source for entering that content on the demo site.</p></div>
