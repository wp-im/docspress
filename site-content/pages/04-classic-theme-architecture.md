<p>Docspress follows the Classic Theme model: PHP templates, a stylesheet header, ordinary hooks, and WordPress content APIs. It does not need a page builder or a theme-owned database model.</p>

<div class="section-summary"><strong>Small boundary, lower risk.</strong> Theme code can shape the reading surface while plugins remain the home for workflows, custom post types, or editor-only features.</div>
