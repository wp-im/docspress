<h2>Use the editor's native blocks</h2>
<p>Images, galleries, captions, lists, tables, and quotes do not need a Docspress-specific data store. The theme supplies spacing, borders, and overflow behavior around the HTML WordPress already outputs.</p>

<h2>Let tables scroll instead of break the page</h2>
<p>On narrow screens, a wide table gets a local scroll region. The document remains readable and the page itself avoids unexpected horizontal overflow.</p>

<blockquote class="docspress-quote"><p>A visual system earns trust when the exceptional block still feels like part of the document.</p><cite>Reading system note</cite></blockquote>
