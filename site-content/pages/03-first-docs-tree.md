<h2>Start with one root</h2>
<p>Create a Page called <strong>Docspress</strong>. Make the six section Pages its direct children. Give those sections menu orders 10, 20, 30, 40, 50, and 60.</p>

<h2>Add documents beneath each section</h2>
<p>Use a normal Page for each document. Its parent determines the branch; its menu order determines the position within that branch. The theme uses the same tree for the sidebar, section index, and Previous / Next links.</p>

<h2>Read the result as a path</h2>
<p>Open any child Page and follow the tree downward. The current branch opens automatically, while the adjacent title remains a normal link even when its toggle is closed.</p>
